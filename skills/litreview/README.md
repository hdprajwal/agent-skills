# litreview

Run a structured, reproducible academic literature review.

Scope the question and inclusion criteria, search widely (Semantic Scholar, arXiv, OpenAlex, citation chasing) with a recorded search log, screen in two passes, extract findings into a comparable matrix, synthesize by theme with an honest gap analysis, and cite cleanly in BibTeX. Hard rules against fabricated citations and abstract-only claims.

## Install

```bash
npx skills add https://github.com/hdprajwal/agent-skills --skill litreview -g
```

## Requires

Web access for searches; optional Semantic Scholar / arXiv / OpenAlex APIs.
