# api-design

Design stable, well-shaped interfaces before implementing them.

Contract-first design for HTTP endpoints, MCP tools, or library APIs: specify inputs/outputs/errors/side-effects up front, name consistently and predictably, give structured recoverable error shapes, bound list responses and make retried writes idempotent, keep the least surface that works, and classify changes additive vs breaking with a versioning/deprecation path. Ends with a review checklist.

npx skills add https://github.com/hdprajwal/agent-skills --skill api-design -g
